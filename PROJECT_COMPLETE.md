# 🎉 MécaCasablanca - Projet Complet

## 📊 Résumé du Projet

MécaCasablanca est une application web mobile-first de type inDrive pour la réparation automobile à domicile à Casablanca. L'application permet aux clients de décrire leur problème, de proposer un prix, et de choisir parmi les offres des mécaniciens vérifiés à proximité.

## 📱 Comment Tester

### 1. Démarrer l'application
```bash
npm run dev
```

### 2. Accéder à la landing page
```
http://localhost:5173/
```

### 3. Tester les comptes premium
- Scroller jusqu'à la section "Comptes Premium"
- Cliquer sur "Se connecter" pour chaque compte
